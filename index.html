ODCS Java SDK

odcs-java-sdk (odcs-core) is a Java 17+ library for the Open Data Contract Standard (ODCS). Work with machine-readable agreements between data producers and consumers — YAML or JSON — on the JVM.

  • Parse — YAML/JSON → typed DataContract
  • Write — contracts back to YAML or JSON
  • Validate — against official Bitol JSON Schemas
  • Build — fluent DataContractBuilder API
v0.1.0 · Java 17+ Maven Central GitHub Details
